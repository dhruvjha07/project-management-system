# Project Management System

A web-based Project Management System built using Flask, SQLAlchemy, and SQLite where users can create projects, assign tasks, track progress, and manage team collaboration with role-based access control.

## 🚀 Live Demo
[Live App](https://project-management-system-production-d934.up.railway.app)

## 📂 GitHub Repository
[GitHub Repo](https://github.com/dhruvjha07/project-management-system)

---

## ✨ Features

### Authentication
- User Signup
- User Login
- Secure Password Hashing
- Logout Functionality

### Role-Based Access

#### Admin
- Create Projects
- Create Tasks
- Assign Tasks to Members
- View All Tasks
- Delete Completed Tasks

#### Member
- View Only Assigned Tasks
- Update Task Status

### Task Management
- Task Creation
- Task Assignment
- Status Tracking
- Overdue Task Highlight

### Dashboard
- Project Overview
- Task Tracking
- Professional UI
